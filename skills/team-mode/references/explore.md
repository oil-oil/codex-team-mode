# Explore

Dispatch one `Explorer` per independent codebase question. Start with one; split into more tracks only when each can investigate and report a distinct subsystem or question without waiting for the others. Give each the repository location, a bounded question, scope, and expected return. Treat known files as leads rather than fixed answers, and avoid duplicate general codebase maps.

Each Explorer starts with fresh context and returns the primary files and symbols, how they connect, and brief evidence. Keep raw search output and unrelated architecture out of the handoff. The main agent combines the maps before deciding what to do next.
